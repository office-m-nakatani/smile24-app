機材動画（3アングル）の置き場所

ファイル名のきまり
  <機材キー>-<アングル>.mp4   … 動画本体
  <機材キー>-<アングル>.jpg   … 一覧タイル用の静止画（動画の中盤を切り出したもの）

  アングル … side / diag / back / seat / walk / run / wide

  ⚠️ この side / diag / back は「取り込んだ順」に付けた記号で、カメラの向きとは
     一致しません（機材ごとにバラバラです）。画面に出る向きの名前と並び順は、
     アプリ側の EQ_ANGLE_SETS に機材ごとに書いてあります。
     動画を足したら、**必ず .jpg を目で見てから**そこへ追記してください。
     ファイル名から推測して書くと逆になります（2026-08-28に実際に「真横と斜め後ろが
     反対」と指摘を受けました）。

大事なこと
・3本そろっていなくても動きます。置いてあるアングルだけが表示され、
  撮っていないアングルのボタンは自動的に消えます。
・アングルが1つだけの機材は、切り替えるものが無いのでタイルを出しません。
・1本も無い機材は「この機材の動画は準備中です」と表示されます。
・アプリ側のコードを直す必要はありません。ここに置くだけで反映されます。
・⚠️ 動画を足したら .jpg（静止画）も一緒に用意してください。無いとタイルが
  黒いままになります。会員のスマホに8MBの動画を勝手に落とさせないために、
  タイルは動画ではなく静止画で見せる作りにしています。
・⚠️ 音声はすべて外してあります（2026-08-28指示）。新しく足す動画も外してください。
  この環境に ffmpeg は無いので、再エンコードせずに音声トラックだけを取り除く
  スクリプトを使いました（映像は1画素も変えずに済みます）。手順はメモリの
  smile24-app-project に記載。外し忘れると、その動画だけ音が出ます。
・動画は16:9（1280x720）で撮ってください。枠を動画の比率に合わせているので、
  縦横比が違うものを混ぜると、その動画だけ上下に黒い帯が出ます。
